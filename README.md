1. 專案用途
本專案開發一個基於 Python 的自動化視覺偵測系統，主要用途包括：
即時物體追蹤：利用 YOLOv8 模型即時辨識攝像頭畫面中的物體（如動物、人物、車輛）。
顏色特徵提取：結合 HSV 顏色空間分析，自動判斷偵測目標的主要顏色，適用於智慧分揀或環境監控。
實作效能展示：展示如何透過「跳幀處理」與「模型輕量化」在一般電腦硬體上實現流暢的 AI 辨識流程。
2. 運行程式
基礎辨識模式：執行標準的物體偵測。
顏色辨識增強模式：執行物體偵測並同時分析顏色。
操作控制
啟動：執行指令後，系統會自動開啟預設攝像頭並下載所需的預訓練權重檔
關閉：點擊影像視窗，並按下鍵盤上的 q 鍵即可安全退出程式。
